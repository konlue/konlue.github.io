# konlue 的博客

**[konlue.github.io](https://konlue.github.io)** — 一个关于 Java 后端与 AI 应用开发的个人技术博客。只写亲手做过或亲手踩过的东西：系统设计复盘、性能优化实录、Agent 工作流实践。

基于 [Astro](https://astro.build/) + [AstroPaper](https://github.com/satnaing/astro-paper) 主题构建，静态输出、零后端。

## 功能亮点

- 🈶 全站中文界面（导航、日期、分页、SEO meta）
- 🌗 明暗双主题，切换时涟漪式过渡
- 📑 长文右侧目录，滚动跟随高亮（scrollspy）
- ✨ 滚动渐入动效，尊重 `prefers-reduced-motion`
- 🔷 mermaid 时序图/流程图，随主题自动重绘
- 🎯 首页 hero 互动点阵：鼠标波纹推开、弹簧归位
- 🔍 全文搜索（Pagefind）、标签页、归档页
- 📡 RSS、sitemap、动态 OG 图、404 页

## 技术栈

Astro 7 · TypeScript · Tailwind CSS v4 · Markdown/MDX · GitHub Actions（自动部署至 GitHub Pages）

## 快速开始

```bash
corepack pnpm dev      # 本地开发
corepack pnpm build    # 生产构建
```

写文章、发布流程、自定义配置位置，见 [操作手册](./docs/操作指南.md)。

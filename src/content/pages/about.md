我是konlue，软件工程专业 2027 届本科生，方向是 Java 后端与 AI 应用开发。

2026.04–2026.08 实习期间，参与数据出境项目二期的开发，负责申报模块与跨系统回调链路的 15+ 个接口，从需求理解到上线交付完整走了一遍。这段经历让我第一次知道，“把功能写出来”和“把系统做可靠”中间隔着多少东西：状态怎么收敛、回调丢了怎么办、缓存什么时候会背叛你。

在校期间我从 0 到 1 做的开源项目：[dam-hub](https://github.com/konlue/dam-hub)，一个企业级图片素材中台，覆盖上传、检索、权限、协同；[dam-scout](https://github.com/konlue/dam-scout)，基于 FastAPI + LangGraph 的 AI 素材策展助手，编排了一条五节点的 Agent 工作流。前者让我理解了工程，后者让我摸到了大模型应用的边界。
